# ArcadeBridge player guide

## Join a room

1. Open the ArcadeBridge Controller webpage.
2. Follow the setup wizard.
3. Enter a recognizable player name.
4. Enter the Host's room code and case-sensitive password.
5. Connect a physical controller or select keyboard input.
6. Press **Connect**.

If the room is locked, the credentials are wrong, or that browser identity is temporarily banned, the page explains why the connection was refused.

## Map controls

Select the virtual Xbox 360 or PlayStation layout. Click a virtual control on the controller picture, then press the physical button/key or move the axis to assign it. Red outlines indicate duplicate assignments. The diagram lights up when inputs are detected.

Xbox 360 output is recommended for most games. Select DualShock 4 only when the Host and game specifically need that virtual controller type. Browser support for controller-specific features varies.

## Calibrate

Use the calibration panel to inspect live stick and trigger values. Increase a stick's inner deadzone only until idle drift disappears. Confirm every direction reaches full range, then save the profile.

Profiles and calibration are saved in the current browser on the current device. Clearing browser site data removes them.

## Ready and disconnect

**Ready** only tells the Host that you are prepared. It does not launch the game. Select **Disconnect** when finished so every sent control is released immediately.
