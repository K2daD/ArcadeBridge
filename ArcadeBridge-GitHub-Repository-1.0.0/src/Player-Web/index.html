ArcadeBridge Controller Help

Room Code: Enter the exact code shown by the Host. It is not case-sensitive.

Room Password: Enter the Host's case-sensitive password. It must be 8–128 characters.

Player Name: Identifies you on the Host so you can be moved, removed, or helped.

Input Source: Choose a gamepad or keyboard. Physical Controller selects which connected gamepad to send.

Host Controller Type: Xbox 360 is the recommended compatibility mode. PlayStation mode provides a virtual DualShock 4 on the Host.

Preferred Slot: Automatic uses the first free P1–P4 position. The Host can move you later.

Controller Mapping: Click a control on the diagram, then press or move the physical input you want assigned. Red controls indicate duplicate assignments.

Calibration: Deadzones stop small unwanted stick movement. Trigger sensitivity changes how quickly triggers respond. Save Profile keeps mappings and calibration in this browser.

Connect: Joins the relay and Host room. Ready tells the Host you are prepared to play. Disconnect releases every control safely.

Signal: The Host calculates connection quality from the controller packets it receives.
