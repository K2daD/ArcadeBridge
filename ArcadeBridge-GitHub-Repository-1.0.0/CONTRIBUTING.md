# Contributing to ArcadeBridge

Bug reports and focused improvements are welcome.

## Before opening an issue

1. Check the latest release and existing issues.
2. Reproduce the problem with a fresh Host room.
3. Use the Host diagnostic report when relevant; it intentionally omits the room password.
4. Never post passwords, private keys, certificates, or personal information.

## Pull requests

1. Fork the repository and create a descriptive branch.
2. Keep changes limited to one clear purpose.
3. Test the Host, player webpage, and Relay path affected by the change.
4. Describe what changed, why it changed, and how it was tested.
5. Preserve safe disconnect behavior: losing a player or Relay connection must release virtual controls.
