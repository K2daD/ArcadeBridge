# Security policy

## Supported version

Security fixes are currently made for the latest published ArcadeBridge release.

## Report a vulnerability

Please use **Security > Report a vulnerability** in this GitHub repository so the report is private. Do not place room passwords, private keys, certificates, personal information, or unredacted diagnostic reports in a public issue.

Include the affected version, the ArcadeBridge component involved (Host, player webpage, or Relay), steps to reproduce, and the impact you observed. You may include a password-safe diagnostic report generated by the Host.

## Operational safety

- Use a unique room password and share it only with intended players.
- Use `wss://` for the public Relay and `https://` for the player webpage.
- Keep signing certificates, DNS credentials, and Relay server secrets outside this repository.
- Verify release checksums before running an unsigned build.
- Close the Host room when play is finished; in-memory room bans then clear.
